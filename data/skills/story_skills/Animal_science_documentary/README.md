# 动物科普纪录片 · 导演叙事手法技能包

## 简介

本技能包为 **动物科普纪录片** 类型故事提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。适用于任何视觉风格。

## 核心理念

- **生存是永恒的主题** — 所有动物叙事的核心是"生存"：觅食、避险、求偶、育幼、迁徙，每个行为背后都是千万年进化的智慧
- **个体承载物种故事** — 选一个"主角"动物，让观众跟着它的视角经历整个故事，而非枯燥的物种介绍
- **科普服务于情感** — 先让观众关心这只动物，科普信息才能被吸收。纯粹的信息是百科，有情感的信息才是故事
- **生命循环** — 出生→成长→繁衍→死亡，这个循环本身就是最有力的叙事

## 技能文件说明

### 1. 叙事规划手法 (`director_planning_narrative.md`)

导演在 **叙事规划阶段** 使用的技法参考，定义动物科普纪录片在主题立意、科普节奏、场景情绪设计与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与科普内核 | 生存主题、个体叙事、情感与科普平衡、生命循环 |
| 叙事结构与科普节奏 | 三幕式自然叙事、段落节奏、悬念驱动、时间压缩与扩张 |
| 分场景情绪与科普设计 | 七大典型科普段落设计、科普信息三种呈现方式、空间科普载体 |
| 声音与音乐方向 | 环境音优先、乐器组合策略、沉默的力量、音效科普功能 |
| 叙事禁则 | 禁止拟人化、禁止编造行为、禁止人为干预、禁止过度戏剧化 |

### 2. 分镜表叙事手法 (`director_storyboard_table_narrative.md`)

导演在 **分镜表制作阶段** 使用的技法参考，定义动物科普纪录片在分镜表中的景别策略、运镜节奏、时长把控、行为分镜设计与转场手法。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 分镜表作为科普叙事节奏核心工具的定位说明 |
| 景别选择 | 大全景生态建立、全景行为全貌、特写科普细节、空镜缓冲 |
| 运镜节奏 | 固定机位观察、缓慢跟踪、高速追焦、手持临场感 |
| 时长把控 | 环境建立时长、行为展示时长、科普特写时长、黄金时长原则 |
| 行为分镜设计 | 行为链完整呈现、关键动作多机位、行为前兆捕捉 |
| 多动物调度 | 主角优先、视轴原则、群体空间交代、亲子距离 |
| 解说与节奏 | 解说服务画面、科普分块输出、关键瞬间留白、名词特写配合 |
| 转场设计 | 硬切/空镜过渡/淡入淡出/光影渐变/匹配转场 |

## 使用方式

本技能包作为 ToonFlow 导演 AI 的叙事手法参考，在故事创作流程中自动加载，指导：

1. **叙事规划** — 确定科普主题、情绪曲线、段落节奏与音乐环境音策略
2. **分镜表生成** — 根据叙事规划输出具体的景别、运镜、时长与转场方案

两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环。
