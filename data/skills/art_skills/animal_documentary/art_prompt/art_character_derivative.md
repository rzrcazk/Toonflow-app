# 动物科普写实纪录片 · 动物角色行为状态变体约束手册

---

必须严格、完整遵循下方全部约束，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

## 一、变体原则

| 原则 | 说明 |
|---|---|
| **物种特征锁定** | 变体必须基于已确定的角色参考图，物种毛色/花纹/体型特征保持一致 |
| **状态叙事服务** | 每种变体对应明确的科普叙事场景，需服务于纪录片内容逻辑 |
| **科普信息准确** | 行为姿态、年龄阶段的形态变化必须符合真实生物学规律 |
| **渐进变化清晰** | 年龄/季节变体中的形态差异必须可辨，不得模糊不清 |
| **单背景独立展示** | 变体图均使用纯净中性灰背景，不加入栖息地场景元素 |

## 二、行为姿态变体

核心变体维度：动物在纪录片中最常见的行为瞬间。

### A. 警觉状态

| 维度 | 视觉特征 |
|---|---|
| 体态 | 四肢微曲，重心前移，身体略低 |
| 头部 | 抬头挺立，双耳竖起朝向威胁方向 |
| 眼神 | 瞳孔扩大，目光锁定前方 |
| 尾部 | 尾巴水平伸直或轻微抖动 |
| 毛发 | 背脊毛发略竖起（兽类），羽毛贴紧（禽类） |

### B. 猎食蓄势 / 潜行

| 维度 | 视觉特征 |
|---|---|
| 体态 | 身体压低贴地，重心后移，后腿蓄力弯曲 |
| 头部 | 头部与脊背水平，目光前视锁定目标 |
| 前肢 | 爪部微张，前肢向前伸展 |
| 尾部 | 尾巴低垂，尖端轻微左右摆动 |
| 整体 | 极度紧绷，肌肉线条明显 |

### C. 全力奔跑 / 冲刺

| 维度 | 视觉特征 |
|---|---|
| 体态 | 四肢完全展开腾空，脊背极度拉伸弯曲 |
| 速度感 | 肌肉线条清晰，关节角度极限 |
| 头部 | 颈部前伸，头部与地面平行 |
| 尾部 | 尾巴水平展开用于平衡 |

### D. 休憩 / 静卧

| 维度 | 视觉特征 |
|---|---|
| 体态 | 侧卧或俯卧，四肢自然收拢 |
| 头部 | 放松，下颌可触地或搭于前肢 |
| 肌肉 | 放松状态，无紧张线条 |
| 眼神 | 半闭或完全闭合，放松表情 |

### E. 幼崽哺育 / 亲代互动

| 维度 | 视觉特征 |
|---|---|
| 成体 | 俯身/侧卧，姿态柔和 |
| 幼崽 | 体型明显小于成体，绒毛更蓬松 |
| 互动 | 幼崽哺乳、亲代舔毛、幼崽依偎等 |
| 整体 | 温馨亲密，成体眼神温柔 |

### F. 对峙 / 领地宣示

| 维度 | 视觉特征 |
|---|---|
| 体态 | 四肢撑直，身体侧展显大 |
| 毛发/羽毛 | 全身毛发竖立（或冠羽展开），增大视觉体型 |
| 口腔 | 张口露牙（兽类）或张喙（禽类），威吓姿态 |
| 眼神 | 怒目直视，瞳孔缩小 |

## 三、年龄阶段变体

| 阶段 | 视觉特征 | 适用场景 |
|---|---|---|
| **幼崽期** | 体型极小，头身比大（头偏大），绒毛蓬松柔软，眼睛占比大，四肢短细 | 繁殖/育幼科普段落 |
| **亚成体** | 接近成体体型但更纤细，花纹开始显现但不完整，行为带有试探性 | 成长过程叙事 |
| **成体** | 完整成熟体型，毛色/花纹完整鲜明，肌肉发达，姿态自信 | 核心角色主要呈现 |
| **老年个体** | 体型略消瘦，毛色暗淡/灰化（尤其面部），伤疤/秃毛区域，动作迟缓 | 生命周期/老龄化科普 |

## 四、季节毛色变体

| 物种类型 | 季节变化规律 |
|---|---|
| **冬毛兽类**（北极狐/雪兔/貂类） | 夏季：棕褐色短毛；冬季：纯白厚毛，厚度明显增加 |
| **换毛兽类**（熊/狼/鹿） | 春季：部分区域毛发稀薄，夏毛短薄；秋冬：厚毛蓬松 |
| **繁殖季禽类** | 繁殖季：羽色鲜艳，冠羽/饰羽充分展开；非繁殖季：羽色暗淡收敛 |
| **热带物种** | 全年毛色稳定，无明显季节变化 |

---

## 五、跨物种适配规则

| 物种类型 | 行为姿态特殊说明 |
|---|---|
| **猫科** | 奔跑时脊背弯曲幅度最大；潜行时腹部几乎贴地 |
| **禽类** | 警觉时冠羽竖起；威吓时翅膀展开增大轮廓 |
| **海洋哺乳** | 无奔跑姿态；改用跃出水面/俯冲/尾击水面等动态 |
| **爬行类** | 无奔跑姿态；威吓时颈部展开/身体膨胀/舌头频繁吐出 |
| **犬科（狼）** | 奔跑时尾部低垂；对峙时尾部高举 |

## 六、状态变体画面规范

**单状态展示图：**
- 单张完整姿态图
- 背景：纯净中性灰
- 视角：最能表现该姿态特征的角度（通常为 3/4 侧面视角）

**多状态对比图（可选）：**
- 同一物种 2-4 个状态横排对比
- 背景：纯净中性灰
- 每个状态下方可注名称（仅在对比图中允许小字注释）

## 八、约束规则

### 必守规则

| # | 规则 |
|---|---|
| R1 | 变体必须基于已有的角色参考图，毛色花纹与原图保持一致 |
| R2 | 行为姿态必须符合该物种的真实运动生物学规律 |
| R3 | 年龄变体的形态差异必须清晰可辨 |
| R4 | 背景必须为纯净中性灰，不加入任何场景环境 |
| R5 | 图中不得出现任何文字、标注或水印 |

### 严禁项

| # | 禁止内容 |
|---|---|
| X1 | 禁止拟人化表情和姿态 |
| X2 | 禁止卡通化、插画化处理 |
| X3 | 禁止出现人类或人类附属物 |
| X4 | 禁止将不同物种的行为特征混用 |
| X5 | 禁止出现解剖学上不可能的姿态 |
