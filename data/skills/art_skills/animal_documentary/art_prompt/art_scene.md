---

必须严格、完整遵循下方全部约束，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

## 一、场景美学原则

| 原则 | 说明 |
|---|---|
| **地理真实性** | 场景必须符合该生态带的真实地貌、植被、气候特征，不得混用不同生态带元素 |
| **生态层次感** | 前景/中景/后景三层次清晰，空间纵深感强，空气透视可见 |
| **自然光为主** | 禁止人工照明，光线来源必须符合时段（太阳/月光/漫射天光） |
| **无人无动物** | 场景图中严禁出现任何动物或人物，纯粹展示自然环境 |
| **镜头感** | 构图参照专业纪录片摄影标准，宽画幅，地平线水平 |

## 二、栖息地类型与色调映射

### 热带草原（非洲/澳洲）

| 维度 | 约束 |
|---|---|
| **主色调** | 金黄/橙褐/大地棕，天空蓝白 |
| **植被** | 稀树草丛（合欢/猴面包树），枯黄草海随风起伏，树冠宽平伞形 |
| **地表** | 红褐土壤，干燥裂纹，稀疏草根残茬 |
| **光照特征** | 强烈侧光/低角度金光，硬边阴影，尘埃悬浮感 |
| **大气** | 干热空气，远处热浪轻微扭曲，尘埃颗粒 |

### 极地冰原（北极/南极）

| 维度 | 约束 |
|---|---|
| **主色调** | 冰白/天蓝/银灰，极光绿（夜间） |
| **地表** | 冰面/雪面/浮冰，裂隙可见，表面反光 |
| **植被** | 几乎无植被，偶有苔藓/地衣（北极） |
| **光照特征** | 极昼：低角度斜射金光；极夜：月光/极光；漫射阴天：冷蓝光 |
| **大气** | 雪粉飘散，冰雾，清透冷空气感 |

### 热带雨林（亚马逊/婆罗洲/刚果）

| 维度 | 约束 |
|---|---|
| **主色调** | 深绿/翠绿/墨绿，树干棕褐，湿润深暗 |
| **植被** | 多层林冠（乔木/灌木/地被），藤蔓缠绕，附生植物，板根巨树 |
| **地表** | 腐殖质厚实深棕，落叶积累，菌类可见，溪流穿越 |
| **光照特征** | 云隙光穿透林冠形成丁达尔效应，林地斑驳光影 |
| **大气** | 湿润水汽，轻雾，高湿度空气感 |

### 温带针叶林（西伯利亚/北美/北欧）

| 维度 | 约束 |
|---|---|
| **主色调** | 深绿/灰绿（针叶），白桦树干白色，冬季白雪 |
| **植被** | 密集针叶树（云杉/松树/冷杉），地面苔藓，白桦林穿插 |
| **地表** | 松针厚积，冬季深雪，树干根部积雪 |
| **光照特征** | 低角度斜射穿透林间，长条形光带，冬季蓝调光 |
| **大气** | 清冷空气，晨雾，树间水汽 |

### 沙漠（撒哈拉/戈壁/阿拉伯）

| 维度 | 约束 |
|---|---|
| **主色调** | 赤红/土黄/沙白，岩石灰褐 |
| **地表** | 沙丘波纹/岩石裸露/砾石铺地，高低落差感 |
| **植被** | 极稀疏：刺状灌木/仙人掌/稀疏杂草 |
| **光照特征** | 正午高角度强光，硬阴影，强反光，热浪扭曲 |
| **大气** | 干热极度，沙尘颗粒悬浮，远处热浪 |

### 海洋 / 珊瑚礁（浅海）

| 维度 | 约束 |
|---|---|
| **主色调** | 蔚蓝/青绿/深蓝，珊瑚礁：橙红/黄绿/紫 |
| **环境** | 珊瑚群落，海草床，岩礁，沙底 |
| **光照特征** | 水面光线折射网格效果，从上向下衰减蓝化，浅水透明见底 |
| **大气/水质** | 清澈蓝绿海水，悬浮颗粒，气泡 |

### 湿地 / 芦苇荡（温带/热带）

| 维度 | 约束 |
|---|---|
| **主色调** | 黄绿/泥褐，水面镜面反光 |
| **植被** | 芦苇/香蒲/莎草，密集挺立，浮水植物 |
| **地表** | 浅水淤泥，水面，泥泞堤岸 |
| **光照特征** | 晨雾弥漫，水面镜面反射，逆光剪影 |

## 三、场景空间规范

| 维度 | 要求 |
|---|---|
| **构图** | 16:9 宽画幅，地平线保持水平，三层次（前/中/后景）分明 |
| **前景** | 近处地表细节（草/岩石/水面/冰面），增强纵深感 |
| **中景** | 核心地貌特征，空旷感或密集感体现生态密度 |
| **后景** | 天空/山脉/地平线，大气透视可见（远处轻微蓝化/雾化） |
| **天候** | 与时段、季节逻辑一致 |
| **镜头** | 广角感，宽阔视野，非鱼眼，无畸变 |

## 四、四视图设定图规范

摄像机固定于场景中心点，向四个方向各拍一张，形成 360° 全环境参考图。

| 视图 | 摄像机方向 | 展示内容重点 |
|---|---|---|
| **前视图（0°）** | 面向主要叙事方向 | 核心地貌和背景天空 |
| **右视图（90°）** | 向右旋转 90° | 右侧地貌/植被/地形变化 |
| **后视图（180°）** | 向后旋转 180° | 背侧环境，与前视图形成对比 |
| **左视图（270°）** | 向左旋转 270° | 左侧地貌/植被/地形变化 |

**画面规范：**
- 布局：同一画面 2×2 网格（左上前视图/右上右视图/左下后视图/右下左视图）
- 严禁：任何动物、人物出现在画面中
- 文字：图中不要有任何文字、标注

## 六、约束规则

### 必守规则

| # | 规则 |
|---|---|
| R1 | 场景地貌必须符合指定生态带的真实地理特征 |
| R2 | 四视图必须是同一场景从四个方向的环视，保持环境一致性 |
| R3 | 画面中严禁出现任何动物和人物 |
| R4 | 前/中/后景三层次必须清晰，纵深感明确 |
| R5 | 光照必须符合指定时段的真实光线特征 |
| R6 | 图中不得出现任何文字、标注 |

### 严禁项

| # | 禁止内容 |
|---|---|
| X1 | 严禁画面中出现任何动物（包括飞鸟远景轮廓、水中鱼影） |
| X2 | 严禁画面中出现任何人类、人造建筑、道路、电线 |
| X3 | 禁止混用不同生态带的植被（如在草原中出现热带棕榈） |
| X4 | 禁止卡通化、插画化、绘画风格处理 |
| X5 | 禁止使用人工舞台光照效果 |
| X6 | 禁止出现任何文字、标注、水印 |
| X7 | 禁止地平线倾斜（保持水平） |
| X8 | 禁止鱼眼镜头效果和强烈桶形畸变 |
