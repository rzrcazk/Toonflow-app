# 动物科普写实纪录片 · 生态道具状态变体约束手册

---

必须严格、完整遵循下方全部约束，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

## 一、衍生原则

| 原则 | 说明 |
|---|---|
| **道具锚定** | 变体必须基于已确定的道具参考图，形态特征保持可辨识 |
| **状态叙事准确** | 每种状态变体对应明确的生态叙事节点，状态变化逻辑合理 |
| **科普信息可读** | 状态差异必须清晰可辨，服务于科普信息的视觉表达 |
| **自然降解逻辑** | 降解/损耗过程必须符合自然规律（腐败顺序/骨化过程/风化程度） |
| **纯道具独立展示** | 所有变体图均使用纯净中性灰背景，无场景、无动物、无人物 |

## 二、状态类型

### A. 新鲜度状态（食物 / 猎物类）

| 状态 | 视觉特征 | 叙事适用场景 |
|---|---|---|
| **活体鲜活** | 表皮完整光泽，颜色鲜艳，眼球透亮（动物），姿态自然 | 捕猎前/觅食前的猎物介绍 |
| **猎获新鲜** | 体表基本完整，但眼球失去光泽，部分毛发凌乱，无明显腐败 | 捕猎成功后的即时展示 |
| **部分消耗** | 躯体部分缺失（明确区域），骨骼部分外露，切面自然 | 进食过程/分食场景描述 |
| **腐败降解** | 皮毛脱落，骨骼逐渐外露，颜色暗褐，质地松软皱缩 | 生态循环/清道夫行为科普 |

### B. 标本化状态（骨骼 / 科普展示类）

| 状态 | 视觉特征 | 叙事适用场景 |
|---|---|---|
| **完整骨骼** | 全套关节连接，骨骼位置解剖准确，乳白色，轻微光泽 | 物种解剖学科普 |
| **单块骨骼** | 单独一块骨骼（头骨/肋骨/前肢骨等），细节超清晰 | 特定骨骼特征科普 |
| **风化骨骼** | 哑白泛黄，表面细裂纹，轻微粉化边缘，野外自然状态 | 野外发现/年代判断科普 |
| **化石化** | 深棕褐色，岩石纹理与骨骼融合，表面石化，部分缺失 | 古生物/进化科普 |

### C. 季节状态（植物性道具）

| 状态 | 视觉特征 | 叙事适用场景 |
|---|---|---|
| **萌发期** | 嫩绿/黄绿色，芽尖细腻，叶片嫩薄半透明 | 春季觅食/食草动物行为 |
| **盛期** | 翠绿饱满，叶脉清晰，叶面光泽，果实饱满 | 食物丰沛期科普 |
| **枯萎期** | 黄褐色，叶片卷曲干燥，叶脉突出，质感脆裂 | 旱季/冬季食物短缺科普 |
| **休眠态** | 裸枝无叶，枝干灰褐，皮纹清晰，轻微霜雪附着 | 冬季栖息地变化科普 |

### D. 使用损耗状态（科研器具类）

| 状态 | 视觉特征 | 叙事适用场景 |
|---|---|---|
| **全新** | 表面光洁，颜色鲜艳，无划痕，标签清晰 | 科研项目启动/器具介绍 |
| **使用中** | 轻微磨损划痕，颜色略暗淡，轻微泥垢附着 | 野外追踪工作场景 |
| **长期使用** | 明显磨损，颜色褪色，泥土/血迹等附着，功能性损伤可见 | 长期科研项目叙事 |

## 三、状态变体画面规范

**单状态图：**
- 单张道具呈现，使用四宫格 2×2（正面/侧面/背面/细节特写）
- 背景：纯净中性灰
- 重点展示该状态最具辨识价值的视觉特征

**状态对比图（可选）：**
- 同一道具 2-3 个状态横排对比
- 背景：纯净中性灰
- 相同视角（通常正面），尺寸一致

## 四、材质状态变化规则

| 材质 | 新鲜/完整 → 降解/损耗演变 |
|---|---|
| **有机毛皮** | 光泽柔软 → 干燥脆硬 → 脱落缺失 → 骨骼外露 |
| **骨骼** | 米白光滑 → 哑白泛黄 → 表面裂纹 → 灰白粉化 → 褐色化石 |
| **植物组织** | 翠绿光泽 → 黄绿过渡 → 枯黄干燥 → 灰褐破碎 |
| **金属（器具）** | 光洁反光 → 轻微划痕 → 氧化哑光 → 锈迹斑斑 |
| **塑料（器具）** | 鲜艳光洁 → 轻微划痕 → 颜色褪色 → 泥垢附着 |

## 六、约束规则

### 必守规则

| # | 规则 |
|---|---|
| R1 | 变体必须基于已有的道具参考图，形态特征保持可辨识 |
| R2 | 状态变化必须符合自然降解/生长/使用损耗的真实规律 |
| R3 | 背景必须为纯净中性灰，不加入任何场景环境 |
| R4 | 图中不得出现任何文字、标注或水印 |

### 严禁项

| # | 禁止内容 |
|---|---|
| X1 | 禁止出现任何动物或人物 |
| X2 | 禁止状态变化不符合生物学/物理降解逻辑 |
| X3 | 禁止卡通化、图标化处理 |
| X4 | 禁止出现与道具本身无关的环境元素 |
| X5 | 禁止过度血腥或令人不适的腐败处理（科普写实级别即可） |
| X6 | 禁止出现地面纹理或投影 |
