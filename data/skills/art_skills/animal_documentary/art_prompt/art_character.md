# 动物科普写实纪录片 · 动物角色基础形象生成约束手册

---

必须严格、完整遵循下方全部约束，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

---

## 一、基础形象原则

| 原则 | 说明 |
|---|---|
| **物种准确性** | 形态、毛色、花纹、体型必须符合该物种真实生物学特征，不得随意创造 |
| **摄影质感** | 写实摄影风格，毛发/羽毛/鳞片超清晰，禁止卡通化、插画化处理 |
| **四视图一致性** | 同一角色的四个视图必须保持物种特征、毛色、花纹完全一致 |
| **中性展示背景** | 纯净中性灰背景，剔除栖息地干扰，专注于角色形象本身 |
| **科普严谨性** | 体型比例、牙齿、爪部、耳型等解剖特征必须准确，不得夸张或简化 |

## 二、动物形态约束

### 大型猫科（狮/虎/豹/猎豹）

| 维度 | 约束 |
|---|---|
| 体型 | 肌肉感明显，肩部隆起，四肢粗壮有力，尾巴修长 |
| 毛色/花纹 | 物种准确：虎纹/豹斑/猎豹实心斑点/狮子沙黄色，禁止混用 |
| 眼神 | 竖椭圆形瞳孔（猫科特征），眼神锐利，金黄/绿色/琥珀色虹膜 |
| 姿态 | 自然站立，四足着地，不得人形站立或坐姿抬手 |
| 质感 | 短毛紧贴肌肉，毛发层次分明，光泽感自然 |

### 猛禽类（鹰/雕/隼/枭）

| 维度 | 约束 |
|---|---|
| 体型 | 双翼收拢时比例准确，站立时爪部抓握有力 |
| 羽毛 | 羽片层次清晰，主飞羽/覆羽/绒羽分层可见，羽色准确 |
| 眼神 | 正圆或微方形瞳孔，黄色/橙色/红色虹膜，眼眶骨突出（猛禽特征） |
| 嘴爪 | 钩形喙利落有力，利爪锋利弯曲，鳞状脚趾清晰 |
| 姿态 | 栖息站立或双翼展开，禁止拟人站立 |

### 海洋哺乳类（鲸/海豚/海象/海豹）

| 维度 | 约束 |
|---|---|
| 体型 | 流线型体型准确，鳍肢比例符合物种特征 |
| 皮肤 | 光滑湿润反光（鲸豚类），或粗糙皱褶（海象类），质感真实 |
| 花纹 | 虎鲸黑白分明，白鲸纯白，海豚腹部白/背部灰，物种准确 |
| 姿态 | 自然游动体态或半出水姿势 |

### 小型哺乳类（狐/狼/熊/兔/鼠）

| 维度 | 约束 |
|---|---|
| 体型 | 体型比例准确，禁止头身比失调的卡通化处理 |
| 毛发 | 绒毛厚度、耳内绒毛、尾巴蓬松度符合物种特征 |
| 面容 | 自然动物表情，禁止微笑/皱眉等拟人化表情 |

### 爬行/两栖类（蛇/蜥蜴/龟/青蛙）

| 维度 | 约束 |
|---|---|
| 鳞片 | 鳞片纹理细腻清晰，色彩花纹物种准确 |
| 眼睛 | 竖瞳/横瞳/圆瞳依物种准确表现 |
| 姿态 | 自然体态，蛇类盘绕/蜥蜴四足着地/龟类缩颈或伸展 |

## 三、毛发 · 羽毛 · 鳞片质感约束

| 类型 | 质感要求 |
|---|---|
| **兽类毛发** | 短毛：贴身光泽感；长毛：层次蓬松，毛尖细腻；底绒：深层可见 |
| **鸟类羽毛** | 羽片边缘清晰，翅膀内侧羽绒柔软，体羽光泽随光线变化 |
| **鱼/鲸皮肤** | 湿润高光，皮纹/纹路可见，禁止干燥哑光处理 |
| **爬行鳞片** | 立体浮雕感，光线下反光角度变化，颜色渐变自然 |
| **干燥状态** | 毛发伏贴，无湿润效果 |
| **湿润状态** | 毛发结团，水珠附着，光泽增强 |

## 四、四视图设定图规范

| 视图 | 说明 |
|---|---|
| **正面图** | 动物正对镜头，全身从头顶到爪底完整展示，四肢自然站立 |
| **右侧面图** | 右侧完整轮廓，体型线条、四肢比例、尾部形态清晰 |
| **后视图** | 后背/臀部/尾巴形态，后肢比例，脊背线条 |
| **面部特写** | 面部从头顶到颈部，眼神/鼻/口/耳细节超清晰 |

**画面规范：**
- 布局：同一画面左至右横排，4:1比例
- 背景：纯净中性灰（无渐变、无阴影、无地面线）
- 光照：自然漫射光，无强烈方向性阴影
- 文字：图中不要有任何文字、标注、水印、测量线

## 六、约束规则

### 必守规则

| # | 规则 |
|---|---|
| R1 | 物种形态必须符合真实生物学特征，不得创造不存在的花纹或形态 |
| R2 | 四个视图必须保持同一个体的毛色花纹完全一致 |
| R3 | 背景必须为纯净中性灰，禁止出现任何栖息地元素 |
| R4 | 动物姿态必须自然，四足动物保持四足着地站立 |
| R5 | 面部特写必须清晰展示眼睛、鼻、口、耳等面部特征 |
| R6 | 图中不得出现任何文字、标注或水印 |

### 严禁项

| # | 禁止内容 |
|---|---|
| X1 | 禁止卡通化、插画化、动漫风格处理 |
| X2 | 禁止拟人化：不得微笑、皱眉、挥手、站立、坐姿抬手 |
| X3 | 禁止出现人类、人的手、人的身影 |
| X4 | 禁止出现笼舍、栅栏、铁链、项圈等人工束缚物 |
| X5 | 禁止体型比例失调的夸张处理 |
| X6 | 禁止混用不同物种的特征（如给狮子画豹纹） |
| X7 | 禁止出现地面纹理、投影、环境光晕 |
