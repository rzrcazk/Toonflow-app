3. 昵称格式参考：XX科普馆 / XX动物世界 / 动物XX说
4. 简介模板：「每天带你认识一种神奇动物 🐾 | 科普向 | 合作私信」

|------|------|------|------|

### 1.3 熟悉即梦 AI 操作要点

- **生图**：粘贴提示词 → 选择模型（越高画质越好，但消耗积分越多）→ 生成
- **图生视频**：上传图片作为首帧 → 粘贴视频描述词 → 每个分镜的视频时长 = 该段文案字数 ÷ 5（四舍五入到整数秒），范围 5-15 秒灵活选择。多数镜头建议落在 10-15 秒区间，保持节奏稳定。→ 生成
- **配音**：输入文案文字 → 选择音色（建议选沉稳男声或温柔女声，试听后决定）→ 生成并下载
- **积分管理**：免费额度有限，用完可切换账号或等每日刷新

## 二、单条视频制作流程

> 以下是你每制作一条视频要走的完整步骤。

### 第 1 步：确定选题（在 Claude 中完成）

在本项目对话中，你可以这样说：

- 「帮我推荐 5 个适合做科普的动物选题」
- 「我想做一期关于猫头鹰的视频，帮我出文案」
- 「给我一个动物名字就行」→ 说"开工 + 猫头鹰"，Claude 会一次性输出全套

**选题方向参考：**
- 冷门但有趣的动物（蜜獾、鸭嘴兽、枪虾）
- 常见动物的冷知识（猫、狗、金鱼）
- 动物之间的对决/互动（蜜獾 vs 眼镜蛇）
- 动物的"反差萌"行为
- 季节性话题（冬眠、迁徙、繁殖季）

### 第 2 步：生成文案（在 Claude 中完成）

Claude 会直接输出约 700-900 字的口播文案（配音时长约 2:20-3:00，加片头片尾成片约 2:30-3:30），包含：
- 故事化的开头（代入感强）
- 给动物角色起名字
- 硬核知识点用大白话讲
- 幽默/反转结尾

**你需要做的**：通读一遍，如果有不满意的地方直接告诉 Claude 修改。

### 第 3 步：生成分镜脚本（在 Claude 中完成）

Claude 会输出一个表格：

| 镜头号 | 对应文案 | 字数 | 建议时长 | 文生图提示词 | 图生视频描述词 | 运镜 | 景别 |
|--------|---------|------|---------|-------------|---------------|------|------|
| 1 | ... | 68字 | 14s | ... | ... | 推镜头 | 中景 |
| 2 | ... | 55字 | 11s | ... | ... | 固定 | 近景 |
| ... | | | | | | | |

表格底部会汇总：总字数 XXX 字 / 总配音时长约 X:XX / 共 XX 个分镜

### 第 4 步：生成图片素材（在即梦 AI 中操作）

1. 打开即梦 AI
2. 逐个复制 Claude 给的「文生图提示词」
3. 粘贴到即梦的文生图功能中
4. 选择模型版本（建议 3.0 起步，积分够用 3.5）
5. 生成图片 → 检查是否满意 → 不满意重新生成
6. 下载所有图片到本地文件夹（建议命名：项目名_01、项目名_02...）

### 第 5 步：生成视频片段（在即梦 AI 中操作）

1. 选择「图生视频」功能
2. 上传刚才生成的图片作为首帧
3. 粘贴对应的「图生视频描述词」
4. 选择时长：每个分镜的视频时长 = 该段文案字数 ÷ 5（四舍五入到整数秒），范围 5-15 秒灵活选择。多数镜头建议落在 10-15 秒区间，保持节奏稳定。
5. 生成 → 下载到本地

**时长选择原则（即梦AI支持 5-15 秒灵活选择）：**
- 直接按分镜表中标注的「建议时长」选择，该时长已根据文案字数精确计算（字数÷5=秒数）
- 即梦时长选择器可精确到每一秒（6s、8s、11s、13s 等均可，不限于 5/10/15 三档）
- 宁可视频长 1-2 秒（剪映可裁剪），不要短了（补不回来）
- 建议时长参考：50字→10s / 60字→12s / 70字→14s / 75字→15s

### 第 6 步：生成配音（在即梦 AI 中操作）

1. 选择即梦的配音/语音合成功能
2. 粘贴完整文案
3. 选择音色（第一次多试几个，选定后固定使用同一音色保持一致性）
4. 生成 → 试听 → 下载音频文件

### 第 7 步：剪映剪辑合成

**导入素材：**
1. 打开剪映电脑版 → 新建项目
2. 导入所有视频片段 + 配音音频

**核心操作：**

1. **拖入配音音频**到时间轴
2. **按顺序拖入视频片段**到视频轨道
3. **逐段对齐**：播放配音，在每句话对应的位置裁剪和调整视频片段
   - 这是最关键也最耗时的步骤
   - 确保每句话的内容和画面是匹配的
4. **添加 BGM**：
   - 剪映素材库搜索"动物""自然"类背景音乐
   - 拖入后降低音量（不超过人声的 30%）
5. **添加音效**：
   - 开头加转场音效
   - 知识点强调处加"叮"或"嗖"
   - 动物画面处加对应叫声（鸟鸣、兽吼等）
6. **识别字幕**：
   - 使用剪映的"智能字幕"功能自动识别
   - 选择字体（推荐：新青年体或类似醒目字体）
   - 调整颜色、描边（加描边或阴影可提升可读性）
7. **最终检查**：完整播放一遍，检查音画同步、字幕准确性
8. **导出**：选择 1080p 或更高分辨率导出

## 三、各平台发布指南

### 3.1 标题策略

在发布前，告诉 Claude「帮我为这个视频生成各平台标题」，Claude 会输出：

| 平台 | 标题风格 |
|------|---------|
| 抖音 | 口语化、设问句、情绪化（"这动物居然不怕蛇？！"） |
| 快手 | 接地气、直接、有冲突（"蜜獾硬刚眼镜蛇，结果万万没想到"） |
| 小红书 | 种草体、emoji、好奇心驱动（"🐾 这个动物太猛了吧！全网都在科普它"） |
| 视频号 | 中性偏正式、知识感（"蜜獾：自然界最无畏的勇士"） |
| YouTube | 关键词密度高、偏搜索优化（"蜜獾为什么不怕蛇？动物科普｜蜜獾生存技能全解析"） |

### 3.2 发布时间建议

| 平台 | 推荐发布时间 |
|------|-------------|
| 抖音 | 12:00-13:00 / 18:00-20:00 / 21:00-22:00 |
| 快手 | 同抖音 |
| 小红书 | 12:00-14:00 / 20:00-22:00 |
| 视频号 | 19:00-21:00 |
| YouTube | 根据受众，中文内容建议北京时间 19:00-21:00 |

### 3.3 发布频率建议

- 起步期：每天 1 条，坚持 30 天
- 稳定期：每天 1-2 条
- 矩阵模式：多账号同步发布，内容差异化（不同动物/不同文案角度）


### 新增：3.4 小红书图文笔记策略

小红书的图文笔记和视频笔记是两套独立的分发逻辑，用同一套素材可以多出一个内容形态，实现双倍曝光。

**图文笔记制作方法：**

1. **素材复用**：从视频制作过程中生成的即梦AI图片中，挑选 6-9 张最好看的
2. **封面图**：第一张图决定点击率，选最有视觉冲击力的那张，可用剪映加文字标题
3. **正文改写**：不要直接复制视频文案，而是改写为小红书阅读风格：
   - 开头用「你知道吗？」「震惊！」「被这个动物圈粉了」等小红书体
   - 正文分短段落（每段 2-3 行），多用 emoji 分隔
   - 知识点用「划重点：」「冷知识：」等标签突出
   - 结尾引导互动（"你还想了解哪种动物？评论区告诉我"）
4. **话题标签**：每篇加 5-8 个标签

**标签模板：**
```
#动物科普 #冷知识 #[动物名] #涨知识 #自然 #神奇动物 #科普 #[具体特征标签]
```

**图文 vs 视频发布节奏：**
- 每发 1 条视频笔记，同步发 1 条图文笔记（内容相同但形式不同）
- 图文笔记和视频笔记间隔至少 2 小时发布，避免被判重复内容
- 图文笔记标题风格要和视频标题有差异

**让 Claude 帮你生成：**
在对话中说「出小红书图文版」，Claude 会基于当前视频文案输出：
- 小红书图文标题（3 个备选）
- 改写后的图文正文
- 推荐使用的图片编号（从分镜表中选）
- 话题标签组合

## 五、效率提升技巧

### 5.1 批量生产模式

1. 一次让 Claude 生成 3-5 个不同动物的完整方案（文案+分镜+标题）
2. 集中在即梦 AI 中批量生图、生视频
3. 集中在剪映中批量剪辑
4. 安排好一周的发布计划，定时发布

### 5.2 积分节省策略

- 即梦 AI 每日有免费额度，每天用完当日额度
- 简单画面用 3.0 模型，关键画面用 3.5
- 豆包也能生图，可作为即梦的备选

### 5.3 快捷指令（在 Claude 中使用）

| 你说的话 | Claude 会做什么 |
|---------|---------------|
| 「开工 + [动物名]」 | 一次性输出：文案 + 分镜表 + 各平台标题 + 封面文案 |
| 「换个选题」 | 推荐新的动物选题 |
| 「这个文案改一下，XXX」 | 按你的要求修改文案 |
| 「帮我分析这个爆款」+ 粘贴文案 | 拆解爆点结构并学习风格 |
| 「出一周的选题计划」 | 输出 7 天的选题安排 |
| 「这段提示词效果不好，优化一下」 | 优化文生图/图生视频提示词 |

#### 6.2 周复盘模板（每周日执行）

每周拿着数据表来找 Claude，说「帮我做周复盘」，并附上本周的数据表截图或文字摘要，Claude 会从以下维度帮你分析：

**复盘五问：**

1. **哪条视频数据最好？为什么？**
   → 分析选题类型、标题风格、发布时间等变量

2. **哪条视频数据最差？可能的原因？**
   → 排查选题吸引力、封面点击率、完播率等问题

3. **各平台表现差异？**
   → 是否某个平台明显跑赢/跑输，调整分发重心

4. **选题类型偏好趋势？**
   → 哪类动物/哪种叙事风格的数据更好，下周多做

5. **下周调整计划？**
   → 基于数据给出下周选题方向、发布策略的具体建议

## 七、常见问题

**Q：视频和配音对不上怎么办？**
A：在分镜阶段就控制好每段文案对应的视频时长。文案短的镜头选 5 秒，中等选 10 秒，长的选 15 秒。剪映中可以通过裁剪视频或调整语速来微调。

**Q：即梦积分不够用怎么办？**
A：每日免费额度用完后等第二天刷新，或用多个账号轮换。关键镜头用高版本模型，次要镜头用低版本节省积分。

**Q：生成的图片不满意怎么办？**
A：回到 Claude 让我优化提示词，加入更具体的描述（光线方向、动物姿态、背景细节）。或者在即梦中多次生成选最好的一张。

**Q：科普内容会不会讲错？**
A：Claude 生成的文案会基于准确的动物知识。但建议你发布前快速搜索验证关键知识点，毕竟账号的专业性是长期口碑。

**Q：多平台发一样的内容会不会限流？**
A：建议做差异化处理：不同标题、不同封面、视频开头结尾略作调整。小红书可以额外做图文版本。
