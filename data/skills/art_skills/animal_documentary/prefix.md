# 全局视觉基础 · 动物科普短视频写实风格

---

必须严格、完整遵循下方全部风格约束与全局规则，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

## 一、风格基因

| 维度 | 定义 |
|---|---|
| **一级风格** | 高清写实自然纪录片（Photorealistic Nature Documentary） |
| **二级风格** | 野生动物摄影 · 自然光 · 4K超清 |
| **情感基调** | 震撼壮阔、治愈温暖、科普严谨、视觉冲击、反差感、停留感 |
| **质感锚词** | 真实摄影质感、自然光照、高清细节、超真实动态 |
| **短视频优先原则** | 画面要在手机小屏上有冲击力，特写和近景优先于大全景 |

## 二、视觉约束

### 核心规则

- **风格**：写实摄影风格，禁止卡通化、插画化、艺术化处理
- **比例**：16:9
- **分辨率**：高清，不低于1080p
- **色温**：根据场景自然调整（日光5500-6500K / 黄昏3000-4000K / 阴天6500-7500K）
- **光线**：自然光为主，禁止人工舞台光效

### 短视频视觉优先级

短视频在手机端播放，大全景细节损失严重。分镜景别应遵循以下优先级：

| 优先级 | 景别 | 适用场景 |
|---|---|---|
| ⭐⭐⭐ 最优先 | 特写 / 大特写 | 眼睛、爪子、羽毛、牙齿等细节，情感连接最强 |
| ⭐⭐⭐ 最优先 | 近景 | 动物上半身或头部，行为清晰，情感可见 |
| ⭐⭐ 次优先 | 中景 | 完整行为展示，捕猎姿势等 |
| ⭐ 点缀使用 | 全景 / 大全景 | 环境建立、场景切换过渡，不宜过多 |

### 场景分类约束

**野生动物场景**
- 背景：荒野、草原、森林、沙漠等自然栖息地
- 禁止：笼子、栅栏、人工建筑、城市背景、项圈、绳索
- 光线：自然环境光，可有金色阳光、云隙光、晨雾

**萌宠场景**
- 背景：温馨室内、自然庭院
- 禁止：杂物堆积、脏乱环境
- 光线：柔和自然光，暖色调

**海洋生物场景**
- 背景：自然海洋、珊瑚礁、深海
- 禁止：鱼缸、人工水族箱（除非剧情需要）、污浊水质
- 光线：水下自然光折射效果

## 四、通用负面提示词（每次文生图必须添加到反向提示词框）

画面中不要出现任何文字、水印、标签、logo、签名。不要出现变形肢体、多余的腿或尾巴、不自然的身体比例。不要出现模糊画面、低分辨率、噪点过多、过度曝光、欠曝。不要出现人类、人的手、人的身影。不要出现卡通风格、动漫风格、插画风格。不要出现拟人化的表情和动作，不要微笑、皱眉、挥手。不要出现家宠化的行为，不要翻肚皮、不要摇尾乞怜。

## 五、提示词构成规则

### 文生图提示词结构

### 图生视频描述词结构（四段，必须按此顺序）
第一段：主体动作（动作动词 + 身体部位 + 方向/角度 + 速度/幅度，20-35字）
第二段：镜头运动（简洁指令，一句话，10-20字）
第三段：环境动态（可见运动元素，1-2句，10-20字）
第四段：固定品质后缀（固定约30字）
