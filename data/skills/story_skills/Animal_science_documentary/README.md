# 动物科普短视频 · 导演叙事手法技能包

## 简介

本技能包为**动物科普短视频**类型提供一套完整的导演叙事手法参考，涵盖从宏观叙事规划到微观分镜执行的全流程指导。面向抖音、快手、小红书、视频号、YouTube等短视频平台，适用于任何视觉风格。

## 核心理念

- **短视频逻辑第一** — 用户在刷视频，不是在看纪录片。前3秒决定去留，每个镜头都要有让用户继续看下去的理由
- **给动物起名字** — 叫"大眼"的仓鸮比"仓鸮（Tyto alba）"更让人记得住。给主角一个名字，观众才会有情感投入
- **知识包在故事里** — 先让观众关心这只动物，科普信息才能被吸收。反差、冲突、悬念是载体，知识是内核
- **爽感和反差是留存武器** — 外表萌/实力强、看似弱/其实狠、普通动物/冷知识炸裂。反差越大，观众越想看完

## 技能文件说明

### 1. 叙事规划手法（`director_planning_narrative.md`）

导演在**叙事规划阶段**使用的技法参考，定义动物科普短视频在主题立意、叙事结构、节奏设计与声音方向上的整体规划方法。

| 章节 | 内容概要 |
|---|---|
| 主题立意与内容核心 | 前3秒留人、给动物起名字、知识包在故事里、反差留存 |
| 叙事结构与节奏 | 钩子→冲突→爽点→收尾短视频黄金结构、悬念设计、节奏起伏 |
| 分场景情绪与内容设计 | 七大段落情绪表、科普信息呈现方式（行为即科普/比喻优先/反差对比） |
| 声音与音乐方向 | 配音带节奏、BGM跟情绪、关键瞬间静音技巧 |
| 叙事禁则 | 禁止平铺直述/开头铺垫太长/情绪全程平均/结尾虎头蛇尾 |

### 2. 分镜表叙事手法（`director_storyboard_table_narrative.md`）

导演在**分镜表制作阶段**使用的技法参考，定义动物科普短视频在分镜表中的景别策略、运镜节奏、时长把控与转场手法。

| 章节 | 内容概要 |
|---|---|
| 分镜表定位 | 每个镜头都要让用户继续看下去 |
| 景别选择 | 特写/近景优先（手机小屏冲击力最强）、全景点到为止 |
| 运镜节奏 | 推镜头制造悬念、固定镜头用于高潮、快切制造爆发感 |
| 时长把控 | 每个镜头固定5秒生成，1个镜头 = 1段5秒视频 |
| 行为分镜设计 | 每镜头只做一件事、关键动作给特写、行为前兆是好内容 |
| 多动物调度 | 主角永远清晰、对峙用正反打 |
| 解说与画面配合 | 解说带着画面走、高潮瞬间解说可以停 |
| 转场设计 | 同场景硬切、场景切换空镜、短视频卡点转场是加分项 |

## 使用方式

本技能包在故事创作流程中自动加载，指导：

1. **叙事规划** — 确定钩子开场、情绪曲线、段落节奏与音乐策略，目标是让用户刷到就停下来
2. **分镜表生成** — 根据叙事规划输出具体的景别、5秒镜头数量、运镜与转场方案

两个文件分工明确、逐层递进，从"为什么这样拍"到"具体怎么拍"形成完整闭环。
