# 分镜表纪录片约束 · 动物科普写实纪录片 · 技法参考

---

## 一、分镜表定位

分镜表是导演将科普剧本转化为镜头语言的核心工具。以下仅提供动物科普写实纪录片风格在分镜表层面的约束规范。

---

## 二、光影与氛围

- **同场戏光影统一** — 一场戏内不应出现两种以上时段光影，除非有明确的叙事时间推进（如晨→昼→暮的时间流逝）
- **生态带色盘绑定** — 每场戏须绑定生态带类型（草原/极地/雨林等）并在镜头组内保持该生态带的色调连续性
- **光源角度规范** — 必须跟随真实太阳位置，描述光影时须标注时段（清晨斜射/正午顶光/黄昏逆光）
- **色温与叙事阶段匹配** — 科普展示段落（清晨/正午）保持准确色温，情感性段落（黄昏/暮色）允许强调橙红暖调
- **光影转场是高级手段** — 时段自然推进（清晨→正午→黄昏）在分镜表中通过空镜 + 色温变化标注时间流逝，不要硬切时段

---

## 三、环境动态

- **环境动态增加画面呼吸感** — 草浪翻涌、水面涟漪、树叶飘落、尘土扬起、云影移动。每 3-4 个行为镜头至少安排一个有环境动态的空镜，避免画面"死掉"
- **纪录片环境元素优先** — 环境动态应选用生态真实元素：风吹草浪、水面微波、飞鸟掠过、云影移动，体现自然环境的真实生命力
- **科普细节空镜** — 地面爪印特写、咬痕树干特写、水坑泥面特写等生态痕迹镜头，可插入行为叙事之间强化科普信息

---

## 四、纪录片动作节奏

- **动物行为节奏需真实** — 潜行缓慢（低速跟踪运镜）、奔跑爆发（高速追焦）、休憩静止（固定镜头长时静观）。动作节奏必须与真实动物行为匹配
- **行为特写捕捉关键** — 爪尖触地的细节、瞳孔扩大的瞬间、颌骨咬合的力度。在分镜表的"动物动作"栏中标注最具科普价值的动作细节
- **群体行为用全景交代** — 迁徙队列、水源聚集、群体捕猎等场景先用大全景建立空间感，再切近景行为特写

---

## 五、景别节奏规范

> **短视频适配**：短视频首镜必须有冲击感或反差感，不以「大全景环境建立」开场。下表景别组合适用于各段落内部推进，而非片头起手式。

| 叙事节点 | 推荐景别组合 | 说明 |
|---------|------------|------|
| 环境建立 | 大全景 → 全景 | 先交代生态地理位置，再建立具体场景（短视频仅用于段落过渡，不用于片头开场） |
| 动物登场 | 全景 → 中景 | 先展示动物在环境中的位置，再切行为中景 |
| 行为展示 | 中景 + 特写交替 | 行为全貌 + 关键细节（爪/眼/嘴）轮切 |
| 高潮行为 | 中景 → 近景 → 特写急切 | 追猎/对峙等高张力行为逐步推进景别 |
| 情感节点 | 近景 → 特写 | 幼崽依偎、亲代舔毛等情感行为用近景特写 |
| 科普展示 | 特写 + 细节特写 | 解剖特征、生态标记等科普内容用极近特写 |
| 段落收尾 | 中景 → 全景 → 大全景 | 行为结束后景别拉远，回归自然环境大图景 |

---

## 六、运镜禁忌

- **禁用快速甩镜** — 急甩、快速横摇与写实纪录片的观察者视角不符
- **禁用花式转场** — 划屏、旋转、虚焦化入等与真实摄影风格不兼容
- **禁用完全静止定格感** — 画面不能像静止照片，环境动态（草浪/风声）必须可感
- **禁用鱼眼畸变** — 纪录片镜头要求画面无明显桶形畸变
- **禁用人工运镜轨迹** — 不允许完美对称的弧形轨迹运镜；推荐手持跟踪感、自然呼吸感

---

## 七、转场规范

| 转场类型 | 适用场景 | 禁止场景 |
|---------|---------|---------|
| 硬切 | 同场戏行为节奏切换（潜行→冲刺）| 跨时段、跨场景的大段落转换 |
| 空镜过渡 | 段落之间的叙事缓冲 | 高张力行为中途插入（破坏节奏） |
| 淡入淡出 | 时段切换（日→夜）、回忆/时间流逝 | 行为高潮段落 |
| 色温渐变 | 时间推进（晨→昼→暮）| 空间跳切（草原→雨林） |

---

## 八、分镜表字段规范（动物科普版）

> **执行格式以 `animal_skills/storyboard.md` v3 规范为准**（含角色锚定、配音时长、导演备注列）。每个镜头对应一个5秒视频片段。景别与运镜已融合进图生视频描述词，不作为独立列输出。本节字段仅供视觉风格参考。

分镜表概念字段（视觉风格参考）：

| 字段 | 说明 | 示例 |
|------|------|------|
| **序号** | 镜头编号 | 01 |
| **画面描述** | 该镜头的核心视觉内容（25-60字） | 猎豹在枯草中身体压低，腹部贴地缓慢接近羚羊 |
| **场景** | 栖息地类型 + 地理区域 | 非洲热带草原，旱季黄昏 |
| **关联资产** | 出现的动物/道具资产名称 | 猎豹·成体（参考图A）、羚羊群（远景） |
| **时长** | 预计镜头时长 | 6s |
| **景别** | 大全景/全景/中景/近景/特写 | 中景 |
| **运镜** | 摄像机运动方式 | 低角度缓慢跟踪，手持自然晃动感 |
| **动物动作** | 动物的具体行为细节 | 四肢交替前移，爪尖触地无声，瞳孔锁定前方 |
| **叙事情绪** | 该镜头服务的科普叙事情绪 | 紧张蓄势，捕猎本能展示 |
| **光影氛围** | 时段 + 光线方案 | 黄昏逆光，橙金草海剪影，浅景深 |

## 九、运镜词速查表

| 运镜方式 | 适用行为 | 禁用场景 |
|---------|---------|---------|
| 低角度缓慢跟踪 | 潜行、步行、觅食 | 不适合大全景环境建立 |
| 高速追焦（长焦追踪） | 奔跑、追猎、冲刺 | 静止行为 |
| 固定广角（三脚架） | 休憩、静态观察、环境空镜 | 不适合高张力行为 |
| 极慢推进 | 睡眠特写、育幼温情 | 行为高潮段落 |
| 鸟瞰下摇 | 大全景环境建立 | 行为特写 |
| 跟随升起 | 动物起身、觉醒、登场 | 奔跑追猎 |
| 手持自然晃动 | 贴近观察、真实感强化 | 极地/沙漠大全景 |
