## 一、道具设计原则

| 原则 | 说明 |
|---|---|
| **科学准确性** | 道具形态、尺寸、质感必须符合真实生物学与生态学事实 |
| **自然质感** | 有机物质感（毛皮/骨骼/植物组织）优先，拒绝人工美化 |
| **生态语境一致** | 道具必须与关联物种的栖息地和生态位一致 |
| **纯道具独立展示** | 道具单独陈列，无动物持有、无人持有、无场景背景 |
| **尺度参照明确** | 道具描述中需包含尺寸感参考（如：与手掌等大/约15cm） |

## 二、道具分类与美学约束

### A. 食物 / 猎物类

| 子类 | 形态约束 | 质感约束 |
|---|---|---|
| **昆虫** | 体节清晰，翅翼透明脉络可见，复眼细节，附肢完整 | 甲壳类：光泽反光；软体昆虫：哑光湿润 |
| **鱼类** | 鳞片紧密反光，鳍条清晰，眼球亮泽，体型比例准确 | 湿润高光，鱼鳞逐片可辨 |
| **小型哺乳猎物** | 完整形体，毛发细腻，无过度血腥处理，科普写实风格 | 毛发光泽自然，腹部皮肤可见 |
| **果实 / 浆果** | 表皮纹理细腻，光泽感自然，成熟色彩饱满 | 表皮蜡质光泽，受光面高光可见 |
| **鸟蛋** | 椭圆形标准，蛋壳斑点/颜色物种准确，表面细微质感 | 哑光石灰质感，表面轻微斑驳 |

### B. 筑巢 / 栖息材料类

| 子类 | 形态约束 | 质感约束 |
|---|---|---|
| **枯草 / 干叶** | 叶脉清晰，自然卷曲弯折，颜色枯黄至灰褐 | 干燥脆裂质感，表面粗糙哑光 |
| **树枝 / 树皮** | 皮纹理清晰，节点、苔藓、裂纹自然 | 木纹细腻，干枯枝条有轻微银白化 |
| **羽毛** | 羽轴清晰，羽片纹路可见，羽端细腻 | 绒羽柔软，飞羽光泽方向性变化 |
| **苔藓 / 泥土** | 苔藓：绒毛质感绿色；泥土：颗粒感，湿润/干燥状态不同色 | 湿润苔藓：翠绿高光；干燥苔藓：灰绿哑光 |

### C. 领地 / 信号类（科普写实）

| 子类 | 形态约束 | 质感约束 |
|---|---|---|
| **爪痕树干** | 竖向平行抓痕，树皮撕裂翻卷，木质外露 | 树皮粗糙，新鲜抓痕处木质嫩黄 |
| **头骨 / 骨骼** | 科普标本级别，骨骼比例准确，骨缝清晰 | 风化骨骼：哑白泛黄；新鲜骨骼：米白光滑 |
| **蜕皮（爬行类）** | 蛇蜕：半透明，鳞片纹路保留完整，呈空壳状 | 半透明质感，内侧哑光外侧轻微光泽 |

### D. 科研辅助道具

| 子类 | 形态约束 | 质感约束 |
|---|---|---|
| **GPS追踪项圈** | 塑料/橡胶颈圈+金属盒体，天线可见 | 橡胶哑光，金属盒体轻微反光 |
| **耳标** | 扁平塑料标签，有编号（数字可模糊处理） | 塑料哑光，边缘可有磨损 |
| **野外测量尺** | 金属软尺或折叠钢尺，厘米/毫米刻度可见（文字模糊） | 金属光泽，轻微锈迹/磨损 |
| **标本采集瓶** | 玻璃广口瓶，瓶盖金属，内部可见模糊内容物轮廓 | 玻璃透明折射，金属盖哑光 |

## 三、多角度设定图规范（四宫格 2×2）

| 宫格位置 | 视图内容 |
|---|---|
| **左上：正面图** | 道具正面，完整展示主要特征 |
| **右上：侧面图** | 道具 90° 侧面，厚度/深度可见 |
| **左下：背面图** | 道具背面，背部特征或连接结构 |
| **右下：细节特写** | 最具辨识价值的局部细节放大 |

**画面规范：**
- 背景：纯净中性灰（无渐变、无地面线）
- 光照：自然漫射光，无强烈方向性阴影
- 文字：图中不要有任何文字、标注、水印
- 禁止：图中不能出现任何动物、人物、手部

## 四、材质渲染约束

| 材质类型 | 渲染要求 |
|---|---|
| **毛皮 / 皮革** | 毛发纤维细腻可见，受光面高光方向一致，皮肤底质隐约可见 |
| **骨骼 / 甲壳** | 表面微观质感（骨孔/甲壳纹路），哑光或轻微光泽 |
| **植物组织** | 叶脉/木纹/纤维结构清晰，颜色渐变自然 |
| **金属（科研器具）** | 哑光金属或高光不锈钢，轻微磨损氧化痕迹 |
| **塑料（科研器具）** | 哑光塑料，轻微使用划痕，颜色均匀 |
| **玻璃（标本瓶）** | 透明折射效果，边缘高光，内部内容物轮廓模糊 |

## 六、约束规则

### 必守规则

| # | 规则 |
|---|---|
| R1 | 道具形态和材质必须符合真实生物学与生态学特征 |
| R2 | 四宫格中四个视图必须是同一道具的不同角度 |
| R3 | 道具独立展示，背景为纯净中性灰，无场景背景 |
| R4 | 细节特写（右下宫格）必须是最具科普价值的局部 |
| R5 | 图中不得出现任何文字、标注或水印 |

### 严禁项

| # | 禁止内容 |
|---|---|
| X1 | 禁止出现任何动物或人物 |
| X2 | 禁止道具被手持、被咬住、被爪持等 |
| X3 | 禁止卡通化、图标化、拟人化处理 |
| X4 | 禁止出现不属于该物种生态位的道具 |
| X5 | 禁止过度美化（如不自然的光晕、光环效果） |
| X6 | 禁止出现地面、桌面等衬底纹理 |
| X7 | 禁止出现超过合理尺度的夸张比例 |
