# 动物科普写实纪录片视觉风格

**风格类型**：animal_documentary  
**适用场景**：动物科普短视频  
**视觉定位**：高清写实自然纪录片，呈现真实动物行为与自然环境

## 使用说明

此风格专为动物科普视频设计，与常规短剧/漫剧艺术风格不同，它强调：

1. **真实性**：写实摄影质感，无艺术化处理
2. **自然性**：自然光照，真实栖息地背景
3. **动态性**：即梦AI可执行的具体动作描述
4. **一致性**：角色锚定描述确保同一动物跨镜头外观一致

## 与即梦AI的配合

- 文生图：使用 `prefix.md` 的风格约束 + 角色锚定描述
- 图生视频：严格遵循四段结构（主体动作→镜头→环境→品质后缀）
- 配音：按段落拆分，每段 ≤240字

## 分类变体

- `野生动物`：荒野背景，强调力量和生存行为
- `萌宠`：温馨室内，暖色调，日常行为
- `海洋生物`：水下光效，深邃蓝绿色调
