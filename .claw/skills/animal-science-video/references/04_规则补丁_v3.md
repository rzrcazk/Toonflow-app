## 一、图生视频描述词规范（替代 v2 六维标准 + 三层深度）

### 1.1 核心原则：给即梦写指令，不是给人写散文

即梦AI视频模型的特性：
- 对提示词**前半段**权重最高，越靠前越优先执行
- 能理解**具体可见的动作**，不能理解抽象概念和心理描写
- 「为什么做」「让观众感受到什么」这类信息对模型完全无效
- 品质后缀词对画面质量有显著提升

因此：**动作放最前面，镜头放第二，环境放第三，品质词兜底。**

### 1.2 提示词四段结构（必须按此顺序）

```
第一段：主体动作（权重最高）
第二段：镜头运动
第三段：环境动态
第四段：固定品质后缀
```

#### 第一段：主体动作（必须占提示词第一句）

描述动物做什么。每个动作描述必须包含四要素：
**动作动词 + 身体部位 + 方向/角度 + 速度/幅度**

示例：
- ✅ 猫头鹰头部突然向右快速旋转90度，定住不动
- ✅ 蜜獾用前爪猛力向下扒开土堆，泥土向两侧飞溅
- ✅ 仓鸮从树枝上向前俯冲而下，双翅完全展开，爪子向前伸出
- ❌ 仓鸮的声学定位系统被触发（抽象，不可见）
- ❌ 头部以精准弧度锁定声源方向（文学化，缺少具体方向和角度）
- ❌ 瞳孔急速收缩（即梦无法渲染瞳孔级别的微动作）

#### 第二段：镜头运动

简洁指令，一句话说清。

示例：
- 固定镜头，持续12秒
- 镜头从中景缓慢推进至面部特写，持续13秒
- 镜头跟随动物向右平移，持续10秒
- 镜头从低角度缓慢上升至平视，持续11秒

#### 第三段：环境动态

只描述画面中**可见的运动元素**，1-2 句即可。

示例：
- 背景草丛随风左右摆动，远处树叶飘落
- 水面波纹缓慢扩散，月光倒影随水波晃动
- 雪花持续飘落，地面积雪被风卷起

#### 第四段：固定品质后缀（每条必加）

```
画面真实，镜头流畅，没有闪烁，动作自然流畅，
极致细节，超真实动态捕捉，清晰自然，高质量
```

### 1.3 字数控制

- 第一段（动作）：20-35 字 —— 核心，不能少
- 第二段（镜头）：10-20 字
- 第三段（环境）：10-20 字
- 第四段（品质后缀）：固定约 30 字
- **总计：70-105 字**（比 v2 的 80-120 字略短，但有效信息密度更高）

### 1.4 完整示例对比

**旧版 v2（给人看的散文）：**

> 画面以中景起幅，镜头用13秒缓慢推进至近景。草丛中一道
> 细微声响触发了仓鸮的声学定位系统，它的头部以精准弧度
> 骤然锁定声源方向——两只高低不对称的耳朵正在实时计算
> 声音的立体坐标，这是大自然用千万年打磨出的生物声纳。
> 镜头采用凝视守候模式，仿佛一个屏住呼吸的旁观者。
> 月光从左侧斜打，颈部羽毛在转动中轻微拉伸，背景草叶
> 随夜风颤动。整体传递出猎手锁定猎物前那种窒息的张力感。

即梦能读懂的部分：仓鸮、转头、草丛、月光 → **动物站着不动，镜头拉一下**

**新版 v3（给即梦看的指令）：**

> 仓鸮头部突然向右快速旋转90度定住不动，随后整个身体
> 前倾压低，双爪在树枝上收紧抓握，颈部羽毛因转动而拉伸
> 展开。镜头固定，缓慢推近至面部特写，持续13秒。背景
> 草丛随夜风左右摆动，月光从左侧照亮面部羽毛细节。
> 画面真实，镜头流畅，没有闪烁，动作自然流畅，极致细节，
> 超真实动态捕捉，清晰自然，高质量。

即梦能读懂的部分：旋转90度、前倾压低、爪子收紧、羽毛拉伸、
推近特写、草摆动、月光 → **动物有明确多步动作，画面有内容**

## 二、动作描写语言规范

### 2.1 核心规则：即梦可执行语言

每个动作必须通过「看得见」测试——
如果把描述念给一个不懂生物学的人听，他能不能画出这个画面？
不能 → 重写。

### 2.2 禁用词 → 替换词 对照表

| 禁用（抽象/文学化） | 替换为（具体/可执行） |
|---|---|
| 锁定目标 / 锁定声源方向 | 头部突然转向[方向]，停住不动，眼睛盯住前方 |
| 声学定位系统被触发 | 耳朵竖起，头部快速左右小幅摆动 |
| 瞳孔急速收缩/扩张 | 眼睛猛然睁大 |
| 攻击预备姿态 | 全身压低贴近地面，后腿弯曲蓄力 |
| 翅膀大幅度展开冲击动作 | 双翅猛然完全张开向下拍打，身体向前跃起离开地面 |
| 皮肤在骨架上的松动感 | 奔跑时背部皮肤大幅度左右晃动 |
| 凝视守候模式 | 固定镜头 |
| 主动追踪模式 | 镜头跟随[动物]向[方向]移动 |
| 反应切入模式 | 镜头快速推近至[部位]特写 |
| 整体传递出XXX的情绪感受 | （删除，不写进提示词） |
| 让观众感受到XXX | （删除，不写进提示词） |
| 这是大自然用千万年打磨的XXX | （删除，不写进提示词） |
| 纪录片质感 / 电影级画质 | （移入品质后缀词，不单独描述） |

### 2.3 即梦不擅长的动作（尽量避免）

以下动作即梦AI当前模型很难准确呈现，优先用替代方案：

| 难以呈现的动作 | 替代方案 |
|---|---|
| 瞳孔变化、眼球转动 | 改为头部转向 + 眼睛睁大/眯起 |
| 喉咙蠕动、吞咽内部动作 | 改为仰头动作 + 嘴巴开合 |
| 毛发单根级别的微动 | 改为整片毛发/羽毛随风摆动 |
| 呼吸起伏（幅度太小） | 改为身体可见的膨胀收缩 |
| 皮肤颜色渐变（章鱼变色） | 改为全身颜色从A色突然切换到B色 |
| 多只动物精确互动 | 简化为一只动物做动作，另一只做反应 |

## 三、「导演备注」列使用规范

v2 中的三层深度信息（行为动机、情绪方向、镜头追踪模式）
并非无用，只是不该塞进即梦提示词。这些信息改为写在
分镜表的「导演备注」列中，供用户在剪映剪辑时参考。

### 导演备注包含三项（每项一句话）：

1. **行为动机**：这个动作背后的生物学原因
   → 例：「不对称耳朵进行声源定位」

2. **情绪方向**：这个镜头要让观众产生什么感受
   → 例：「猎手锁定前的窒息张力」

3. **剪辑提示**：音效、转场、节奏方面的建议
   → 例：「此处可加心跳音效渐强；与下一镜硬切」

### 导演备注示例

```
动机：不对称耳朵定位声源，精确到±1度
情绪：猎手屏息锁定的张力
剪辑：加虫鸣环境音突然静止，心跳声渐入
```

## 四、镜头行为设计规范（从 v2 保留，微调）

### 4.1 核心原则：行为弧线

12个镜头的动作强度必须跟着叙事节奏起伏，
禁止全片维持同一能量级别：

开头 1-2镜 → L1 舒缓静态，建立角色气质
发展 3-6镜 → L2 中等动态，行为与知识点强关联
高潮 7-9镜 → L3 强烈动态，全片视觉冲击最强
收尾 10-12镜 → L1 或 L4，回归舒缓或幽默反差收场

### 4.2 行为强度分级（用即梦可执行语言重写）

**【L1 舒缓】** 适用于开头和结尾

- 单脚站立，身体轻微左右晃动，眼睛缓慢眨动
- 用嘴缓慢梳理胸前羽毛/前爪舔舐皮毛
- 站立不动，仅胸腔随呼吸缓慢起伏膨胀
- 头部缓慢向左转动约120度，再缓慢转回

**【L2 中等】** 适用于知识讲解段落

- 整个身体上下快速弹跳3-4次（测距行为）
- 头部快速左右摆动，幅度约45度，连续3次
- 耳羽/背毛突然竖直立起，身体绷紧
- 双翅完全展开向两侧伸展，随后收回抖动
- 仰头将猎物向上抛起，张嘴接住吞入

**【L3 强烈】** 适用于故事高潮和冲突段落

- 全身羽毛/毛发瞬间炸开膨胀至正常体积两倍
- 从高处向下高速俯冲，翅膀收拢贴紧身体
- 前爪猛然向前伸出击打，爪尖张开
- 全身压低贴地，后腿弯曲蓄力，尾巴绷直
- 从地面猛然向上跃起，四肢完全伸展

**【L4 幽默/反差】** 适用于反转结尾段落

- 全身蓬松站在原地，头部缓慢歪向一侧
- 前爪/后爪反复抓挠自己脸部和耳朵
- 身体突然向一侧倾倒，四脚朝天后翻回
- 慢慢转头看向镜头方向，全身保持僵硬不动

### 4.3 禁止行为清单

以下行为全片累计出现不超过 2 次：
- 简单眨眼（无其他配合动作的纯眨眼）
- 原地轻微拍翅/挥爪（幅度过小无视觉效果）
- 小幅度低头（无后续动作的纯低头）
- 尾羽/耳朵单独微动（无身体配合的孤立局部动作）

**新增禁止项：**
- 全片不得出现超过 3 个「固定镜头 + 动物基本不动」的组合
- 每个镜头的动物至少有一个**涉及身体位移或姿态大幅度变化**的动作
  （头部转动、肢体伸展、身体压低/跃起等均算，纯呼吸和眨眼不算）

### 4.4 行为真实性要求

所有行为必须是该动物真实存在的生物学行为。

常见真实行为参考（已用即梦可执行语言改写）：

**猛禽类（猫头鹰/鹰/隼）**
→ 头部快速上下弹跳式摆动3-4次（测距行为）
→ 身体前倾压低，眼睛上方瞬膜快速横向闭合（俯冲准备）
→ 落地后双翅向前张开罩住猎物，身体压低（mantling护食）
→ 身体前弓，嘴巴张大，从口中吐出一个灰色圆形食丸

**猫科动物**
→ 后腿向后蹬直，背部大幅度向上弓起再放平（伸展）
→ 双眼缓慢闭合再缓慢睁开，持续约2秒（慢眨眼示好）
→ 双耳突然向后压平贴紧头部，身体压低（攻击预备）
→ 尾巴末端快速左右抖动，身体保持匍匐不动（猎食前）

**蜜獾/獾类**
→ 奔跑时背部松弛的皮肤大幅度左右甩动
→ 嘴巴大张，嘴角向上翻起露出牙齿（威胁低吼）
→ 前爪快速交替向下挖掘，泥土向后方飞溅（挖掘蜂巢/洞穴）

**海洋生物**
→ 螳螂虾前臂向内蜷曲贴紧身体，保持不动2秒后猛然向前弹出击打
→ 水母伞状身体反复收缩缩小再膨胀张开，节律性上下移动
→ 章鱼全身皮肤颜色从红棕色突然切换为白色，触手同时蜷曲

## 五、负面提示词补充规则（从 v2 保留）

在即梦AI生成图片/视频时，反向提示词框中追加以下内容
（与 02_核心参考 中的负面提示词模板叠加使用）：

### 动物行为类负面提示词（每次必加）

```
不要出现拟人化的表情和动作，不要微笑、皱眉、挥手。
不要出现家宠化的行为，不要翻肚皮、不要摇尾乞怜、
不要做出讨好姿态。不要出现动物与人类互动的画面。
不要出现物理上不可能的身体姿态。
```

### 捕猎场景类负面提示词（涉及捕食时加）

```
不要出现猎物的清晰正脸。不要出现猎手和猎物面对面
对视的构图。猎手必须处于主动进攻或追逐姿态，
不要出现猎手与猎物并排静立的画面。
```

## 六、执行检查清单（替代 v2 版检查清单）

每次生成分镜后自查：

**提示词结构检查：**
□ 每条视频描述词的第一句是否是具体的动物动作？
□ 动作描述是否包含：动作动词 + 身体部位 + 方向/角度 + 速度/幅度？
□ 是否有任何抽象描述残留？（动机、情绪、比喻、文学修辞）
□ 镜头运动是否在第二句用简洁指令交代？
□ 是否每条都附带了固定品质后缀？
□ 总字数是否在 70-105 字范围内？

**行为质量检查：**
□ 是否有至少 2 个 L3 强烈行为镜头？
□ 「固定镜头+动物基本不动」的组合是否不超过 3 个？
□ 每个镜头是否至少有一个涉及身体位移/姿态大幅变化的动作？
□ 禁止行为是否超出 2 次限制？
□ 所有行为是否符合该动物真实生物学特征？

**行为弧线检查：**
□ 行为强度是否有高低起伏（L1→L2→L3→L1/L4）？
□ 高潮段（7-9镜）是否是全片动作最强烈的部分？

**导演备注检查：**
□ 每个镜头是否在「导演备注」列填写了行为动机？
□ 每个镜头是否有情绪方向标注？
□ 关键镜头是否有剪辑提示（音效/转场建议）？
