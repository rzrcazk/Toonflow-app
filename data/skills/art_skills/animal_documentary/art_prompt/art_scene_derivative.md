# 动物科普写实纪录片 · 场景变体约束手册

---

必须严格、完整遵循下方全部约束，并严格按提示词模板格式生成提示词；仅输出提示词正文，不得附加任何解释、说明、注释、标题或其他额外文本。

---

## 一、衍生原则

| 原则 | 说明 |
|---|---|
| **空间结构一致** | 变体必须基于已确定的场景参考图，地形/地貌/植被布局保持一致 |
| **景别驱动叙事** | 不同景别对应不同的科普叙事节点（介绍环境/展示行为/特写细节） |
| **时段切换准确** | 光线色温、阴影长度、天空颜色必须符合真实日照规律 |
| **天候生态合理** | 天候变化必须符合该生态带的气候特征（草原不出现暴风雪） |
| **无人无动物** | 所有变体图中严禁出现任何动物或人物 |

---

## 二、景别变体

| 景别 | 视角距离 | 展示内容 | 纪录片叙事功能 |
|---|---|---|---|
| **大全景** | 极远景，鸟瞰或超广角 | 完整生态地理面貌，地平线可见 | 环境宏观介绍，生态位置交代 |
| **全景** | 远景，水平广角 | 场景全貌，前中后景三层次清晰 | 标准环境建立镜头 |
| **中景** | 中等距离 | 场景主体局部，植被/地形细节可见 | 行为发生地点交代 |
| **近景** | 较近距离 | 地面/植被/水面/岩石的具体细节 | 环境质感特写，生态细节补充 |
| **特写** | 极近距离 | 单一材质/植物/地表细节 | 科普特定元素的细节介绍 |

## 三、时段变体

| 时段 | 色温 | 光照特征 | 视觉关键词 |
|---|---|---|---|
| **黎明破晓** | 4000-5000K，冷紫转橙 | 地平线橙粉色曙光，天空蓝紫渐变，长而平行的晨影 | 晨曦，天空变色，破晓光芒，冷暖交接 |
| **清晨** | 5000-6000K，金黄光 | 低角度斜射暖金光，长影斜切地面，晨雾可见 | 晨雾，金色光芒，长条阴影，露水 |
| **正午** | 5500-6500K，白光 | 顶光直射，阴影短小垂直，强反光，高对比 | 强烈阳光，顶光，高对比，热浪（沙漠） |
| **黄昏金光** | 3000-4000K，橙金色 | 低角度逆光/侧光，天空橙红紫，长金色阴影 | 夕阳橙红，黄金时刻，逆光剪影，晚霞 |
| **暮色收尾** | 2500-3500K，深橙蓝 | 太阳已落，天空深蓝橙边际，轮廓光，柔光 | 蓝调时刻，暮光，轮廓渐消 |
| **夜间月色** | 4000-5000K，冷蓝银色 | 月光从上方漫射，软阴影，轮廓发亮，深暗背景 | 月光，冷蓝，神秘，银色边际 |
| **夜间星空** | 极低（星光），深蓝/黑 | 无月或月弱，满天星空，极暗地面，仅轮廓可见 | 星空，银河，深邃，极暗 |

## 四、季节变体（按生态带适配）

### 热带草原（旱季 / 雨季）

| 季节 | 视觉特征 |
|---|---|
| **旱季** | 草地枯黄，地面龟裂，树木落叶，水坑干涸，尘土飞扬 |
| **旱季末** | 最枯萎状态，地表赤裸，水源枯竭 |
| **雨季初** | 嫩绿新芽破土，水坑积水，地表湿润 |
| **雨季盛期** | 深绿浓郁，草高及腰，水源丰沛，植被浓密 |

### 温带（春 / 夏 / 秋 / 冬）

| 季节 | 视觉特征 |
|---|---|
| **春季** | 嫩绿新叶，花朵点缀，残雪融化，地面湿润 |
| **夏季** | 翠绿茂密，光照充足，高饱和色彩 |
| **秋季** | 金黄/橙红/棕褐叶色，落叶堆积，光线暖黄 |
| **冬季** | 白雪覆盖，枯枝无叶，冷蓝光调，冻结水面 |

### 极地（极昼 / 极夜 / 融冰期）

| 季节 | 视觉特征 |
|---|---|
| **极昼夏季** | 冰雪部分融化，苔藓绿色，积水，低角度连续光照 |
| **秋季冻结** | 冰面重新形成，部分积雪，冷蓝调 |
| **极夜冬季** | 深黑背景，极光（绿/紫色）或月光，冰雪反光 |

## 五、天候变体

| 天候 | 视觉特征 | 适用生态带 |
|---|---|---|
| **晴天** | 蓝天白云，硬阴影，高饱和 | 所有 |
| **阴天** | 灰白天空，漫射柔光，无明显阴影 | 所有 |
| **薄雾** | 远景模糊，空气不透明，湿润低对比 | 雨林/湿地/温带森林 |
| **细雨** | 雨丝可见，地面反光，植被湿润，水面涟漪 | 热带/温带 |
| **暴风雨前** | 乌云压境，光线暗黄，强风草木倾斜 | 草原/温带 |
| **暴风雨中** | 暴雨倾盆，能见度低，闪电可选 | 草原/热带 |
| **沙尘暴** | 橙黄色混浊空气，能见度极低，阳光橙红 | 沙漠/草原干旱地带 |
| **暴风雪** | 白色雪粒飞扬，能见度低，树枝积雪 | 极地/高山/温带冬季 |
| **雨后彩虹** | 清新空气，湿润地面，彩虹横跨天空 | 草原/热带 |

## 六、四视图规范

与场景基础图相同格式：摄像机固定于场景中心点，向四个方向环视，形成 2×2 网格。

| 宫格位置 | 视图内容 |
|---|---|
| **左上：前视图（0°）** | 主视角方向，核心地貌 |
| **右上：右视图（90°）** | 右侧环境 |
| **左下：后视图（180°）** | 背侧环境 |
| **右下：左视图（270°）** | 左侧环境 |

**严禁画面中出现任何动物和人物。**

## 八、约束规则

### 必守规则

| # | 规则 |
|---|---|
| R1 | 变体必须保持与基础场景图的地形/地貌空间结构一致 |
| R2 | 时段色温和光照特征必须符合真实日照规律 |
| R3 | 天候变化必须符合该生态带的气候地理特征 |
| R4 | 季节变化的植被/积雪状态必须符合该生态带的物候规律 |
| R5 | 画面中严禁出现任何动物和人物 |
| R6 | 图中不得出现任何文字、标注 |

### 严禁项

| # | 禁止内容 |
|---|---|
| X1 | 严禁画面中出现任何动物（包括飞鸟、水中鱼影等） |
| X2 | 严禁出现任何人类、人造建筑、道路、电线 |
| X3 | 禁止将不属于该生态带的天候施加其上（如草原出现暴风雪） |
| X4 | 禁止不符合物候规律的季节植被混搭 |
| X5 | 禁止卡通化、插画化处理 |
| X6 | 禁止使用人工照明效果 |
| X7 | 禁止地平线倾斜 |
| X8 | 禁止出现任何文字、标注、水印 |
