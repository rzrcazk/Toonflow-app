# 纪录片约束 · 动物科普写实纪录片 · 技法参考

---

## 一、色调体系与画面基调

- **色调基底** — 全片色调跟随生态带和时段自然变化：草原金黄（5500K）、极地冷蓝（8000K）、雨林深绿（6000K）、黄昏橙红（3000K）。整体色彩还原真实，饱和度中等（65-80%）
- **自然色温贯穿全片** — 色温必须符合真实日照规律和生态环境特征，不得人为渲染非自然色彩
- **色盘先行原则** — 段落规划须先确定生态带类型与时段，再确定色温与光影方案，确保"科普信息对了，视觉情绪也对了"
- **禁用色域** — 荧光色、霓虹色、人工舞台色彩均不符合写实纪录片风格

---

## 二、光影方案体系

- **光影即叙事** — 7 套光影方案对应不同时段和叙事节点，导演规划阶段应在段落层面确定光影基调，而非逐镜指定
- **光源角度** — 跟随真实太阳位置变化，不得固定方向

| 光影方案 | 方案名 | 色温 / 色调 | 适用叙事节点 |
|---|---|---|---|
| A | 黎明金光 | 4000-5000K，冷紫转暖橙 | 动物清晨出发觅食、黎明破晓揭幕 |
| B | 清晨侧光 | 5000-6000K，金黄暖光 | 日常行为展示、晨间觅食 |
| C | 正午高光 | 5500-6500K，白光顶照 | 追逐捕猎、高对比行为展示 |
| D | 黄昏金时 | 3000-4000K，橙红逆光 | 情感性段落、水源聚集、壮阔结尾 |
| E | 阴天漫射 | 6500-7500K，冷蓝柔光 | 雨季科普、行为观察镜头 |
| F | 夜间月光 | 4000-5000K，冷蓝银色 | 夜行动物科普、神秘行为揭秘 |
| G | 极光 / 极夜 | 极低色温，深蓝绿 | 极地物种科普、极夜环境介绍 |

- **时段色温必须与叙事段落对应** — 不得在中午段落插入黄昏橙光，光影逻辑需闭合
- **转折点用光影变化** — 时段推进（晨→昼→暮）在段落衔接时用空镜 + 光影切换标注过渡

---

## 三、质感方向

- **写实摄影纪实感** — 写实野生动物纪录片的核心：毛发根根可辨、地表颗粒感真实、大气效果自然
- **自然质感锚点** — 这是画面质感的核心。不是CG渲染，不是卡通插画，是4K野外摄影的真实观感
- **材质真实** — 动物毛皮/羽毛/鳞片、植被/岩石/水面的材质必须可信。禁止"塑料感"、"插画色彩"、"过度磨皮"
- **写实不等于粗糙** — 本风格强调纪录片摄影的质感表达（清晰毛发、自然光泽、大气透视），通过构图与光影放大感染力，而非依赖后期特效

---

## 四、纪录片场景空间元素

写实纪录片世界观特有的场景元素及其视觉叙事功能：

- **大全景 / 鸟瞰** — 天然的环境交代镜头，宏观介绍生态地理位置，建立观众的空间认知
- **空镜自然细节** — 风吹草浪、水面涟漪、树叶落下、云影移动。每 3-4 个行为镜头安排一个环境空镜，增加叙事呼吸感
- **生态特写** — 爪印、粪便、食物残留、巢穴入口等生态痕迹，服务于科普内容的视觉佐证
- **段落间用场景空镜过渡** — 本风格有丰富的栖息地素材（不同时段/天候/景别），段落衔接优先用空镜 + 解说词缓冲，不要硬切行为镜头
- **转折点用视觉而非字幕** — 优先使用画面手段（景别跳切、光影变化、空镜隐喻）传递叙事信息，而非依赖字幕说明

## 五、纪录片音效与音乐

动物科普纪录片的声音层次约束：

### 音乐选择

- **自然环境底乐** — 轻柔管弦乐铺底，不宜喧宾夺主，保留环境音的主导地位
- **行为高潮段落** — 打击乐 + 弦乐推进，配合捕猎/奔跑/对峙的紧张节奏
- **科普展示段落** — 轻柔木管乐（长笛/双簧管），温和知识感，不抢画面
- **情感性结尾段落** — 弦乐 + 钢琴，情感升华，适合日落大全景或繁育结局
- **夜间/极地段落** — 极简电子 + 环境音，冷峻神秘感

### 乐器组合策略

| 叙事阶段 | 乐器组合 |
|---|---|
| 环境建立 / 开场 | 长笛独奏 或 弦乐轻铺 |
| 行为观察 / 日常 | 轻柔管弦乐 + 环境音 |
| 捕猎 / 对峙 | 打击乐 + 弦乐急进 |
| 情感 / 育幼 | 钢琴 + 弦乐柔和 |
| 夜间 / 极地 | 极简电子 + 环境音 |

### 纪录片环境音层次

- **核心环境音** — 风声、鸟鸣、虫鸣、流水声、草叶摩擦、脚步踩草/踩沙/踩冰
- **行为音效** — 捕猎扑击声、咆哮声、翅膀振翅声、争斗碰撞声
- **每场戏标注 1-2 个核心环境音**，帮助后续音效设计。环境音层次越丰富，纪录片场景越有沉浸感
