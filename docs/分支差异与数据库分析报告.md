### 2.3 关键发现

#### ✅ 当前分支新增表
- `memories` - Agent 记忆表（使用 UUID 主键，支持向量 embedding）
- `o_scriptNovelMap` - 剧本与小说章节映射表（支持多对多关联）
- `o_agentWorkData` - Agent 工作数据表（已补充到 initPg.ts）

#### 📝 表用途说明

**`o_scriptNovelMap` 表的作用**：

master 分支中，剧本和小说章节只能通过 `o_script.novelId` 字段建立**一对多**关系（一个剧本只能对应一个章节）。

当前分支新增 `o_scriptNovelMap` 表后，支持**多对多**关系：
- 一个剧本可以对应多个小说章节
- 一个小说章节也可以被多个剧本引用

使用代码位置：
- [`src/routes/scriptAgent/setPlanData.ts`](src/routes/scriptAgent/setPlanData.ts) - 保存剧本时自动建立关联
- [`src/routes/script/addScript.ts`](src/routes/script/addScript.ts) - 手动添加剧本时可指定关联章节

**`o_agentWorkData` 表的作用**：

存储 Agent 工作过程中的临时数据，包括：
- 剧本 Agent 的故事骨架、改编策略、完整剧本
- 生产 Agent 的分镜表格、工作台数据等

| 表数量 | 25 张 | 27 张 (public.sql 实际) |
| 表结构定义 | initDB.ts | initPg.ts |
| 配置方式 | 硬编码 | 支持环境变量切换 |

### 5.2 表结构增减

| 变化类型 | 表名 | 说明 |
|---------|------|------|
| ➕ 新增 | memories | Agent 记忆表（UUID 主键，支持向量 embedding） |
| ➕ 新增 | o_scriptNovelMap | 剧本 - 小说映射关系表 |
| ➖ 缺失 | o_agentWorkData | **代码中未定义，但数据库实际存在** |

### 5.3 master 分支 o_agentWorkData 表定义

```typescript
// master: src/lib/initDB.ts
{
  name: "o_agentWorkData",
  builder: (table) => {
    table.increments("id");
    table.integer("projectId");
    table.string("episodesId");  // 注意：master 是 string 类型
    table.string("key");
    table.text("data");
    table.integer("createTime");
    table.integer("updateTime");
    table.primary(["id"]);
    table.unique(["id"]);
  },
}
```

### 5.4 public.sql 中 o_agentWorkData 实际定义

```sql
CREATE TABLE "public"."o_agentWorkData" (
  "id" int4 NOT NULL,
  "projectId" int4,
  "episodesId" int4,      -- 注意：PG 是 int4 类型
  "key" varchar(255),
  "data" text,
  "createTime" timestamptz,
  "updateTime" timestamptz
)
```

**字段差异**:
- `episodesId`: master 是 `string`，当前分支 PG 是`int4`
- 时间字段：master 是`integer` 时间戳，当前分支 PG 是` timestamptz`
