## 一、为什么做这个赛道？

**流量优势：** 动物科普内容自带治愈、猎奇、三农标签，平台算法对自然类科普有推荐倾斜，比泛娱乐赛道竞争压力小，爆款生命周期长。

**数据参考：** 头部博主 180 万粉丝，累计 1900 万点赞，单条最高 330 万点赞。

**核心逻辑：** 高清画质 + 故事化讲述（反转/冲突）+ 大白话表达硬核知识 = 用户愿意点赞、收藏、分享。

## 四、制作流程（精简版）

```
第1步：选题 + 文案
  → Claude 生成动物科普文案（约 700-900 字 / 配音 2:20-3:00，成片 2:30-3:30）

第2步：分镜 + 提示词
  → Claude 生成分镜表格（10-12 个分镜，含文生图提示词 + 图生视频描述词 + 每段字数和建议时长）

第3步：生成素材（即梦AI自动化）
  → 用提示词生成图片 → 图生视频（固定5秒/镜头）
  → 文案转配音（选合适音色）

第4步：剪映剪辑
  → 导入视频片段 + 配音音频
  → 对齐音频与画面（关键步骤）
  → 添加 BGM（音量低于人声）
  → 添加音效（开头转场音效 + 动物叫声 + 知识点强调音效）
  → 识别字幕 → 调整字体/颜色/描边
  → 精细检查 → 导出

第5步：发布
  → 多平台分发（抖音/快手/小红书/视频号/YouTube）
  → 每个平台用对应风格的标题
```

## 五、关键注意事项

1. **视频时长匹配**：文案句子长度要和视频片段时长对应，避免音画不同步
2. **图片清晰度**：生成后可超清处理，画质越高越好
3. **音频对齐**：剪映中最花时间的步骤，务必逐段对齐
4. **BGM 音量**：不要盖过人声
5. **积分管理**：即梦AI 有积分限制，可用多账号轮换或选择合适模型版本节省积分


### 负面提示词模板（在即梦AI生图时添加到反向提示词框）

```
【通用负面提示词（每次必加）】
画面中不要出现任何文字、水印、标签、logo、签名。不要出现变形肢体、
多余的腿或尾巴、不自然的身体比例。不要出现模糊画面、低分辨率、
噪点过多、过度曝光、欠曝。不要出现人类、人的手、人的身影。
不要出现卡通风格、动漫风格、插画风格（除非特别要求）。

【萌宠主题额外添加】
不要出现攻击性姿态、龇牙、受伤画面。不要出现脏乱环境、
杂物堆积。不要出现不自然的毛色（如彩虹色、荧光色）。

【野生动物主题额外添加】
不要出现笼子、栅栏、人工建筑、城市背景。不要出现项圈、
绳索等人工束缚物。不要出现血腥画面、猎杀场景。

【海洋生物主题额外添加】
不要出现陆地背景、空气中的场景。不要出现鱼缸、人工水族箱
（除非文案需要）。不要出现污浊水质、垃圾漂浮物。
```

## 七、爆款文案范例

#### 范例一：野生动物猎奇类型（蜜獾）

> 都说蜜獾天不怕地不怕，这话用在阿壮身上，那真是一点都不夸张。刚满半岁的阿壮，就敢独自挑战蜂巢，结果一爪子下去，就被蜜蜂蛰得满脸包，疼得他嗷嗷直叫……

**爆点结构分析：**
- 开头强代入（"都说XXX，用在XX身上"）
- 角色命名（阿壮）→ 增加拟人感和亲切度
- 知识点故事化（皮肤厚、抗蜂毒 → 用"硬刚"故事包装）
- 结尾反转幽默（追野蜂撞树干 → 轻松收尾）

---

#### 范例二：萌宠反差萌类型（猫）

> 别看布偶猫长了一张仙女脸，我家的团团，那可是猫界的"社会猫"。三个月大的时候，第一次见到镜子里的自己，直接炸毛弓背，对着镜子就是一通哈气。那架势，你说她是在照镜子呢，还是在约架呢？……后来团团终于发现，镜子里那个"对手"永远打不赢也打不输，气得她一屁股坐在镜子前面，开始舔爪子——打不过就算了，先美容吧。

**爆点结构分析：**
- 开头反差代入（"仙女脸"vs"社会猫"）
- 角色命名（团团）→ 可爱拟人
- 日常行为故事化（照镜子 → 包装成"约架"）
- 结尾：拟人化幽默收束（"打不过就美容"）
- **适用风格**：暖色调、软光、室内场景、近景为主

---

#### 范例三：海洋生物视觉奇观类型（水母）

> 你可能觉得水母就是海里飘着的一坨果冻，但如果我告诉你，有一种水母能"长生不老"，你信吗？它叫灯塔水母，学名可没这么浪漫，但人家的本事是真的硬核。当灯塔水母受伤或者衰老到快不行的时候，它不是躺平等死，而是直接把自己"倒带"回婴儿状态，重新开始生长。没错，就像你打游戏读档重来一样……科学家到现在都没完全搞明白它是怎么做到的，只知道如果人类学会这招，理发店可能第一个倒闭——毕竟谁还需要植发呢？

**爆点结构分析：**
- 开头颠覆认知（"果冻"→"长生不老"）
- 类比降维（"打游戏读档"解释细胞逆分化）
- 硬核知识轻松讲（灯塔水母的转分化能力）
- 结尾：跳跃式幽默（长生不老→理发店倒闭→植发梗）
- **适用风格**：深海蓝色调、光线穿透水面的效果、中远景为主

---

#### 范例四：动物对决类型（螳螂虾 vs 蛤蜊）

> 要说海底谁的拳头最硬，螳螂虾"铁拳哥"说第二，没人敢说第一。别看铁拳哥体长才十几厘米，这一对鳌足打出去的速度，堪比一颗点22口径子弹出膛。今天铁拳哥盯上了一只死守不出的大蛤蜊，蛤蜊心想：我壳这么硬，你能拿我怎样？铁拳哥二话不说，抡起拳头就是一顿猛锤——"砰砰砰"，水里都能听见闷响。三拳下去，蛤蜊壳裂了条缝；五拳下去，壳直接碎了一角。蛤蜊：说好的铁壁防御呢？！……但你以为铁拳哥天下无敌？也不是。有一次他对着鱼缸玻璃练拳，一拳下去——玻璃碎了，水漏了，自己也傻了。

**爆点结构分析：**
- 开头立人设（"拳头最硬"、"铁拳哥"）
- 数据震撼（子弹速度类比）
- 对决叙事（双方视角切换，蛤蜊的内心OS）
- 拟声词渲染（"砰砰砰"、"闷响"）
- 结尾双反转（以为无敌→打碎鱼缸→自己傻了）
- **适用风格**：海底光影、微距特写+动态冲击镜头
